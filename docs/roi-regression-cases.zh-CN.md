# ROI 快路径回归样本清单

本清单用于 `T2-4 ROI 快路径回归样本`。

## 场景列表

### Case 1：稳定锁定

- 画面稳定对准屏幕至少 10 秒
- 目标：验证进入 ROI 快路径后不会频繁回退

### Case 2：轻微水平移动

- 手持状态下轻微左右平移
- 目标：验证 ROI 扩边后仍能保持锁定

### Case 3：轻微俯仰变化

- 画面保持可读，但角度持续缓慢变化
- 目标：验证 ROI 快路径在透视变化下能否持续命中

### Case 4：瞬时失焦

- 先稳定锁定，再快速制造一次短时失焦
- 目标：验证失败后能回退全图扫描并重新锁定

### Case 5：快速离开再回到码区

- 画面先完全离开屏幕，再重新对准
- 目标：验证 `_hasTracking` 状态不会长时间锁死

### Case 6：模式探测后稳定传输

- autodetect 成功识别后保持会话稳定
- 目标：验证 mode lock 后不再持续四模式轮询
